# Архив прежнего планшетного GUI

Ветка разработки: `TT-2.0`, версия мода: `2.0.0`. `main` не изменяется.

Эта папка сохраняет старые экраны планшета, выбор команды/голосование, их виджеты,
текстуры и 2D-модели, соответствующие тесты, а также незавершённую панель классов
и её пользовательские материалы. Они **не входят** в sourceSets Gradle и итоговый JAR.
Пути перенесённых материалов перечислены в `archived-paths.json`.

`ButtonTextureSpec` также сохранён в активных исходниках: его публичные перегрузки
использует общий `GuiTextureRenderer`. Общие `ui/`, текстурный рендерер,
`TabletDataViewport`, реестр классов и его иконки остаются для независимых интерфейсов
и совместимости данных. Наличие этих общих компонентов не открывает старый планшет.

Старые UI-тесты перенесены вместе с удалёнными из runtime экранами. Активные тесты
проверяют автомат 3D-планшета, отсутствие старых экранов в sourceSets/JAR, ресурсы,
общие UI-компоненты и серверную логику. Серверные проверки, пакеты, ID, данные игрока
и требования матча не заменялись автоматическим выбором команды или класса.

В 2.0.0 старого режима LEGACY нет. Новый функциональный интерфейс пока не реализован;
функции голосования, команды и класса через планшет временно недоступны.
Исторические инструкции в этом архиве описывают прежние этапы и не применяются к 2.0.0.
