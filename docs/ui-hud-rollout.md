# Tactical UI: HUD and rollout

## Статус rollout

Новый UI является production-путём по умолчанию для voting, tablet, clans, contract tracker и HUD. Сетевой
протокол и серверные проверки не менялись. Отдельный runtime-переключатель не добавлен: после достижения
паритета он создавал бы второй неподдерживаемый UI-путь. Для отката до завершения ручной приёмки используется
последняя стабильная сборка.

Неиспользуемые вложенные legacy-экраны подтверждения пока сохранены в `TabletScreen`. Их удаление выполняется
отдельно после одного стабильного релиза, как предусмотрено планом; до ручной приёмки они не расширяются и не
вызываются production-кодом.

Телеметрия поведения игроков не добавлялась. Технические проблемы ресурсов остаются в opt-in диагностике,
а отсутствие необязательного map preview обрабатывается штатным placeholder без спама в лог.

## HUD layout contract

`HudAnchorManager` задаёт детерминированные safe-area зоны для модернизированных уведомлений:

- `topCenter` — AirDrop под стандартной зоной bossbar;
- `spectatorHint` — нижняя центральная подсказка над hotbar-зоной.

Lives/Players намеренно возвращён к прежнему виду и размещению справа от hotbar: `X<lives>` и
`X<alivePlayers> (<remainingLivesTotal>)`, без backing plate и адаптивного переноса. AirDrop сохраняет
семантику «новое сообщение заменяет старое», переносит packet-строку максимум на две строки и нормализует
слишком тёмный accent. Spectator hint сохраняет прежние клавиши и блокировку hotbar. Все три overlay уважают
`hideGui` и политику открытого экрана.

Death transition по-прежнему блокирует input, не ставит игру на паузу и закрывается только по серверной
длительности. Title переносится максимум на две строки, subtitle — на три; narration содержит оба текста.
При `Screen Effects = 0` fade-in отключается. После закрытия предыдущий экран намеренно не восстанавливается —
это прежняя игровая семантика.

## Collision matrix

| Сцена | AirDrop | Lives/Players | Spectator hint | Ожидаемый результат |
|---|---:|---:|---:|---|
| Обычная игра | возможно | да | нет | top-center и hotbar-side не пересекаются |
| Узкий viewport 320×180 | возможно | да, legacy clamp справа | нет | проверить прежнее поведение рядом с hotbar |
| Spectator lock | возможно | нет | да | hint ниже центра, AirDrop сверху |
| Открыт любой Screen | нет | нет | нет | overlays скрыты по прежней политике |
| `hideGui=true` | нет | нет | нет | ничего не рисуется |
| Death transition | нет | нет | нет | полноэкранный input-lock screen |

Геометрия 320×180 и обычной ширины закреплена unit-тестом. Пересечения со сторонними HUD невозможно надёжно
предсказать без их reservation API; это остаётся ручным сценарием.

## Финальная ручная проверка

1. Повторить voting → team → map flow мышью и клавиатурой; во всех голосованиях проверить закрытие по Esc.
2. Проверить MapVote с 0/1/16 картами, preview «Раскольск» и «Советский город», scroll и длинные имена.
3. Открыть все страницы tablet, сделать purchase/unlock/upgrade при достаточном и недостаточном балансе.
4. Проверить clans как outsider/member/owner, длинные списки, формы name/tag/color и все подтверждения.
5. Проверить contract с 0/16 целями, scroll, крайние координаты игрока/целей и повторное открытие tracker.
6. Проверить HUD при 320×180 и обычном viewport: normal/danger, AirDrop с максимальной строкой, spectator,
   `hideGui`, chat/scoreboard/bossbar и сторонний hotbar.
7. Проверить Death с максимальными title/subtitle, звуком, истечением duration и `Screen Effects = 0`.
8. Повторить ключевые сцены на RU/EN и GUI scale 1–4; выполнить resource reload и снова открыть MapVote/tablet.
