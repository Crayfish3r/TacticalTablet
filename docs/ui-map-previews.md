# Map vote previews

Карточка карты автоматически ищет необязательное изображение в клиентских ресурсах. Отсутствие файла не является ошибкой: UI рисует детерминированную заглушку.

## Параметры файла

| Параметр | Значение |
| --- | --- |
| Формат | PNG, RGBA |
| Размер | **96 × 54 px** |
| Соотношение сторон | **16:9** |
| Цветовое пространство | sRGB |
| Текст и рамка внутри изображения | не добавлять |

Полный путь: `src/main/resources/assets/tacticaltablet/textures/gui/maps/map_<hash>.png`.

`<hash>` — восемь строчных шестнадцатеричных цифр стандартного Java `String.hashCode()` от точного имени карты, присланного сервером, включая регистр и пробелы:

```java
String fileName = String.format(Locale.ROOT, "map_%08x.png", mapName.hashCode());
```

Например, имя `test` соответствует `map_00364492.png`.

Добавленный ресурс для `Раскольск`: `map_14b815ff.png`.

Добавленный ресурс для `Советский город`: `map_0b30f167.png`.

## Отображение

- В обычной трёхколоночной раскладке превью выводится в исходном размере 96 × 54 px.
- В более узком окне оно уменьшается с сохранением 16:9.
- UI проверяет наличие ресурса один раз при создании карточки, а не каждый кадр.
- Выбранная карта обозначается состоянием самой карточки; статус не запекается в PNG.
